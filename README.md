# 공업수학 학습 스튜디오

Kreyszig 『공업수학 10판 하』 11장 Fourier 해석과 12장 편미분방정식의 교재 예제를 계산하고 그래프로 보여 주는 학습 프로그램입니다.

## 실행 방법 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 **Python 3.10 이상**을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"**를 선택하십시오.
2. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP**으로 받아 압축을 풀거나 `git clone`을 사용합니다.
3. 폴더 안의 **`실행.bat`**을 더블클릭합니다.
   - 처음 한 번은 가상환경(`.venv`)을 만들고 필요한 패키지(PySide6, NumPy, SciPy, SymPy, Matplotlib)를 설치합니다. 인터넷이 필요하며 몇 분 걸립니다.
   - 그다음부터는 바로 프로그램 창이 열립니다.
   - 문제가 생기면 `실행.bat`이 원인(Python 없음, 설치 실패, 오류 내용)을 보여 주고 멈춥니다.

## 프로그램 사용

1. 왼쪽 위 목차에서 장 → 절(예: `11.2 · 반구간 전개`)을 펼칩니다. 위쪽 검색창에 `11.2-3`, `열`, `막`처럼 입력하면 해당 절과 예제만 남습니다.
2. 절 아래의 `교재 예제 11.2-3 · 반파정류기 (15쪽)` 같은 교재 예제를 누르면 입력이 채워지고 **바로 계산**됩니다. 각 절 마지막의 **사용자 지정**을 누르면 함수·매개변수를 직접 입력할 수 있습니다. 직접 입력한 내용은 교재 예제를 골랐다가 다시 사용자 지정으로 돌아와도 절마다 그대로 남아 있습니다.
3. 오른쪽에 그래프 탭, **수치 표**, **학습 설명**(정의·유도·코드 해설)이 나타납니다.
4. **값을 바꾸면 자동으로 다시 계산**이 켜져 있으면 슬라이더나 숫자를 바꾸고 잠시 멈출 때 다시 계산하며, 보던 탭은 그대로 유지됩니다. 계산이 1초보다 오래 걸린 구성은 자동 계산을 쉬므로 **계산하기**(Ctrl+Enter)를 누르십시오. Esc는 계산을 취소합니다.
5. 그래프 바로 아래 **재생 막대**로 변화를 재생합니다.
   - **시간별** 그래프는 곡선 하나가 실제 시간에 따라 움직이고, 시공간 히트맵에서는 시간선이 아래에서 위로 움직입니다.
   - 11.1 현재 부분합·오차는 N=0, 1, 2, …로 곡선 모양이 바뀌고, 진행파 분해는 시각별 칸이 차례로 나타납니다.
   - 가로축이 시간인 외력·에너지 그래프는 시간 순서대로 그려집니다. 그 밖의 그래프는 정지 그래프입니다.
   - ▶ 재생, ⏸ 일시정지, ■ 정지(원래 그래프로), ◀◀/▶▶ 약 10%씩 이동, ←/→ 한 프레임씩 이동. 오른쪽에서 속도(0.25×~4×)와 방식(한 번·반복·왕복)을 고릅니다.
   - 현·막대·막의 움직임은 **변화 과정** 탭에서 재생합니다.
6. 입력 칸은 클릭해 선택했을 때만 휠로 값이 바뀌므로 폼을 스크롤해도 값이 바뀌지 않습니다.
7. 그래프 위에서 **Ctrl+휠**로 마우스 위치를 중심으로 확대·축소하고, **Shift+휠**로 좌우 이동, **더블클릭**으로 원래 범위로 돌아갑니다.
8. 수치 표의 셀을 선택하고 Ctrl+C를 누르면 전체 자릿수로 복사되어 엑셀에 붙여 넣을 수 있습니다. 화면에는 6자리로 표시되며, 셀 위에 마우스를 올리면 전체 값이 보입니다.
9. 글자가 작으면 **보기** 메뉴(Ctrl+= 크게, Ctrl+- 작게, Ctrl+0 기본)를 쓰십시오. 그래프 글자도 함께 커지며 다음 실행에도 유지됩니다.
10. 11·12장 본문 예제(번호 기준 48개)가 프리셋 53개로 모두 들어 있으며, 교재에 실린 수치는 자동 테스트로 확인합니다([docs/COVERAGE.md](docs/COVERAGE.md)).

## 코드 구성 한눈에 보기

계산은 세 층으로 나뉩니다. 화면(`ui`)은 입력을 모아 주제(`topics`)에 넘기고, 주제는 수학 계산(`core`)을 불러 결과·표·그래프를 만듭니다. `core`는 Qt를 전혀 쓰지 않으므로 노트북이나 테스트에서 그대로 불러 쓸 수 있습니다.

| 폴더·파일 | 역할 |
|---|---|
| `main.py` | 프로그램 시작점 (`실행.bat`이 실행) |
| `engineering_math/ui/` | 화면: 목차 트리, 입력 폼, 자동 계산, 계산 프로세스, 그래프·표, 재생 막대 |
| `engineering_math/topics/` | 주제별 입력 명세·계산 연결·그래프, 학습 설명, 교재 예제 목록 |
| `engineering_math/core/` | 수학 계산: 수식 해석, Fourier 계수, 변환, PDE 해, 구적 |
| `tests/` | 해석해·교재 수치와 비교하는 자동 테스트 (`python -m pytest tests`) |
| `만들기.ipynb` | `core`를 불러 교재 순서로 계산을 재현하는 해설 노트북 |

교재 절과 코드의 대응은 다음과 같습니다.

| 교재 | 화면·입력 (`topics/`) | 수학 계산 (`core/`) |
|---|---|---|
| 11.1 Fourier 급수 | `fourier.py` | `fourier.py`, `analysis.py` |
| 11.2~11.6 반구간·강제진동·근사·Sturm–Liouville·직교급수 | `chapter11_series.py` | `chapter11.py` |
| 11.7~11.10 Fourier 적분·변환·DFT·변환표 | `chapter11_transforms.py` | `chapter11.py`, `quadrature.py` |
| 12.1 기본개념, 12.4 분류·D'Alembert, 12.6 직사각형 정상 상태, 12.7~12.12 | `chapter12.py` | `chapter12.py`, `quadrature.py` |
| 12.2~12.3 진동하는 현 | `wave.py` | `pde.py` |
| 12.5~12.6 열전도 | `heat.py` | `pde.py` |
| 학습 설명 | `chapter11_lessons.py`, `chapter12_lessons.py` | — |
| 교재 본문 예제 프리셋 53개 | `textbook.py` | — |

각 주제는 `inputs`(입력 명세), `compute(params)`(계산 → `Result`), `figures(result)`(그래프)를 가진 클래스이며, 어떤 주제가 어떤 화면 구성에 연결되는지는 `topics/catalog.py`에 모여 있습니다. 파일별 설명은 [docs/HISTORY.md의 코드 구조](docs/HISTORY.md#코드-구조), 설계는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)를 참고하십시오.
