## 처음 사용하는 분께

### 실행 방법 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 **Python 3.10 이상**을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"**를 선택하십시오.
2. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP**으로 받아 압축을 풀거나 `git clone`을 사용합니다.
3. 폴더 안의 **`실행.bat`**을 더블클릭합니다.
   - 처음 한 번은 가상환경(`.venv`)을 만들고 필요한 패키지(PySide6, NumPy, SciPy, SymPy, Matplotlib)를 설치합니다. 인터넷이 필요하며 몇 분 걸립니다.
   - 그다음부터는 바로 프로그램 창이 열립니다.
   - 문제가 생기면 `실행.bat`이 원인(Python 없음, 설치 실패, 오류 내용)을 보여 주고 멈춥니다.

### 프로그램 사용

1. 왼쪽 위 목차에서 장 → 절(예: `11.2 · 반구간 전개`)을 펼칩니다. 위쪽 검색창에 `11.2-3`, `열`, `막`처럼 입력하면 해당 절과 예제만 남습니다.
2. 절 아래의 `교재 예제 11.2-3 · 반파정류기 (15쪽)` 같은 예제를 누르면 입력이 채워지고 **바로 계산**됩니다. 수식을 직접 입력해도 됩니다.
3. 오른쪽에 그래프 탭, **수치 표**, **학습 설명**(정의·유도·코드 해설)이 나타납니다.
4. **값을 바꾸면 자동으로 다시 계산**이 켜져 있으면 슬라이더나 숫자를 바꾸고 잠시 멈출 때 다시 계산하며, 보던 탭은 그대로 유지됩니다. 계산이 1초보다 오래 걸린 구성은 자동 계산을 쉬므로 **계산하기**(Ctrl+Enter)를 누르십시오. Esc는 계산을 취소합니다.
5. 그래프 바로 아래 **재생 막대**로 그래프가 그려지는 과정을 봅니다. 시간·차수별 곡선이 여러 개인 그래프는 한 개씩 나타나고, 곡선이 한두 개인 그래프는 왼쪽부터 그려지며, 시공간 히트맵에서는 시간선이 아래에서 위로 움직입니다. **재생**, **일시정지**(지금 프레임에서 멈춤), **정지**(멈추고 원래 그래프로) 단추가 따로 있고, ◀◀/▶▶는 전체의 약 10%씩, ←/→ 키는 한 프레임씩 이동합니다. 막대 오른쪽에서 속도(0.25×~4×)와 방식(한 번·반복·왕복)을 고릅니다. 시간에 따른 해(현·막대·막의 움직임)는 **변화 과정** 탭에서 재생합니다. 마지막 프레임이 원래 그래프입니다.
6. 그래프 위에서 **Ctrl+휠**로 마우스 위치를 중심으로 확대·축소하고, **Shift+휠**로 좌우 이동, **더블클릭**으로 원래 범위로 돌아갑니다.
7. 수치 표의 셀을 선택하고 Ctrl+C를 누르면 전체 자릿수로 복사되어 엑셀에 붙여 넣을 수 있습니다. 화면에는 6자리로 표시되며, 셀 위에 마우스를 올리면 전체 값이 보입니다.
8. 글자가 작으면 **보기** 메뉴(Ctrl+= 크게, Ctrl+- 작게, Ctrl+0 기본)를 쓰십시오. 그래프 글자도 함께 커지며 다음 실행에도 유지됩니다.
9. 11·12장 본문 예제 50개가 모두 들어 있으며, 교재에 실린 수치는 자동 테스트로 확인합니다([docs/COVERAGE.md](docs/COVERAGE.md)).

### 코드 구성 한눈에 보기

계산은 세 층으로 나뉩니다. 화면(`ui`)은 입력을 모아 주제(`topics`)에 넘기고, 주제는 수학 계산(`core`)을 불러 결과·표·그래프를 만듭니다. `core`는 Qt를 전혀 쓰지 않으므로 노트북이나 테스트에서 그대로 불러 쓸 수 있습니다.

| 폴더·파일 | 역할 |
|---|---|
| `main.py` | 프로그램 시작점 (`실행.bat`이 실행) |
| `engineering_math/ui/` | 화면: 목차 트리, 입력 폼, 자동 계산, 계산 프로세스, 그래프·표, 재생 막대 |
| `engineering_math/topics/` | 주제별 입력 명세·계산 연결·그래프, 학습 설명, 교재 예제 목록 |
| `engineering_math/core/` | 수학 계산: 수식 해석, Fourier 계수, 변환, PDE 해, 구적 |
| `tests/` | 해석해·교재 수치와 비교하는 자동 테스트 (`python -m pytest tests`) |
| `만들기.ipynb` | `core`를 불러 교재 순서로 계산을 재현하는 해설 노트북 |

교재 절과 코드의 대응은 다음과 같습니다.

| 교재 | 화면·입력 (`topics/`) | 수학 계산 (`core/`) |
|---|---|---|
| 11.1 Fourier 급수 | `fourier.py` | `fourier.py`, `analysis.py` |
| 11.2~11.6 반구간·강제진동·근사·Sturm–Liouville·직교급수 | `chapter11_series.py` | `chapter11.py` |
| 11.7~11.10 Fourier 적분·변환·DFT·변환표 | `chapter11_transforms.py` | `chapter11.py`, `quadrature.py` |
| 12.1 기본개념, 12.4 분류·D'Alembert, 12.6 직사각형 정상 상태, 12.7~12.12 | `chapter12.py` | `chapter12.py`, `quadrature.py` |
| 12.2~12.3 진동하는 현 | `wave.py` | `pde.py` |
| 12.5~12.6 열전도 | `heat.py` | `pde.py` |
| 학습 설명 | `chapter11_lessons.py`, `chapter12_lessons.py` | — |
| 교재 본문 예제 50개 | `textbook.py` | — |

각 주제는 `inputs`(입력 명세), `compute(params)`(계산 → `Result`), `figures(result)`(그래프)를 가진 클래스이며, 어떤 주제가 어떤 화면 구성에 연결되는지는 `topics/catalog.py`에 모여 있습니다. 파일별 설명은 아래 [코드 구조](#코드-구조)를 참고하십시오.

목록은 실제로 지원하는 조합만 제공합니다. 같은 PDE라도 임의 경계조건을 모든 해법에 적용할 수 있는 것은 아닙니다. 반무한 열·파동은 같은 계산 모듈의 두 구성으로 연결됩니다. DFT·aliasing 추가 실험은 Fourier 급수의 추가 분석에서 계속 사용할 수 있습니다.

필요한 계산 모듈만 가져오며, 그래프의 Qt 캔버스는 탭을 처음 열 때 생성합니다. PDE 표는 원본 배열을 참조하고 CSV는 ZIP에 순차적으로 기록합니다. 입력이 동일하면 현재 성공 결과를 재사용합니다. 기존 JSON 설정 버전 1·2의 불러오기를 유지합니다.

이전 Tkinter·Streamlit 소스는 제거하였습니다. 노트북의 참조와 DFT 내보내기를 현재 `engineering_math/`로 옮기고 이전 수학 검사는 pytest에 통합하였습니다. 노트북만으로 소스가 재생성되지는 않습니다. 검사·배포 도구는 `scripts/`, 설계·성능 기록은 `docs/`에서 관리합니다.

[설계 문서](docs/ARCHITECTURE.md)와 [측정 결과](docs/PERFORMANCE.md)를 참고하십시오. 현재 소스는 1.7이며, 보존된 `dist/`의 1.5 실행 파일·ZIP은 이전 버전입니다. 새 구조는 `실행.bat`으로 실행하십시오.

공업수학의 수식, 수치 계산 및 그래프를 연결하는 데스크톱 학습 프로그램입니다. Kreyszig 『공업수학 10판 하』 **11장 Fourier 해석·12장 편미분방정식 순서의 학습 모듈**을 제공합니다. 아직 공업수학 전체 또는 교재의 모든 예제·경계조건을 지원하는 것은 아닙니다.

## 푸리에 급수의 정의

함수는 구간 $[-L,L]$에서 주어지고 주기는 $2L$로 가정합니다.

$$f(x)\sim a_0+\sum_{n=1}^{\infty}\left[a_n\cos\frac{n\pi x}{L}+b_n\sin\frac{n\pi x}{L}\right]$$

$$a_0=\frac{1}{2L}\int_{-L}^{L}f(x)\,dx$$
$$a_n=\frac{1}{L}\int_{-L}^{L}f(x)\cos\frac{n\pi x}{L}\,dx,\qquad b_n=\frac{1}{L}\int_{-L}^{L}f(x)\sin\frac{n\pi x}{L}\,dx$$

상수항은 $a_0$이며 $a_0/2$가 아닙니다. `numpy.trapezoid()`로 계수를 적분합니다. `n`은 개별 조화파의 번호, `N`은 부분합의 마지막 차수입니다. `num_points`는 적분 표본 수이며 `M`은 별도의 DFT 표본 수입니다.

현재 부분합, 여러 N의 비교, MSE·RMSE·최대 절대 오차, 계수 표와 스펙트럼을 제공합니다. 추가 분석에는 Gibbs 확대, 진폭·위상, DFT·FFT·급수 비교, Aliasing 실험, 적분 안정성, N별 오차 곡선이 있습니다. 비교 N을 비워도 계산할 수 있습니다. 애니메이션은 0차부터 계산한 현재 N까지 재생합니다.

### 급수, 연속 변환, DFT 및 FFT의 차이

푸리에 급수는 주기 함수의 이산적인 조화파 계수를 구합니다. 연속 푸리에 변환은 비주기 함수를 연속 주파수의 관점에서 다룹니다. 예를 들어 $F(\omega)=\int_{-\infty}^{\infty}f(x)e^{-i\omega x}dx$라는 정의를 사용할 수 있습니다. 이 앱은 **연속 푸리에 변환의 무한 구간 적분을 구현하지 않습니다**.

DFT는 유한 표본 $y_j$에 대해 $X_k=\sum_{j=0}^{M-1}y_j e^{-2\pi i jk/M}$를 계산합니다. FFT는 같은 DFT를 효율적으로 계산하는 알고리즘입니다. 앱에서는 직접 DFT와 `numpy.fft.fft`를 비교합니다. 구간 끝점은 중복하지 않으며, 시작점 $-L$의 위상을 보정한 계수는 $c_k=X_k e^{i\pi k}/M$입니다. 주파수 단위는 cycles/x입니다. DFT CSV에는 원래 복소 변환값과 보정 계수, 양측 크기 및 위상이 함께 저장됩니다. 거의 0인 크기의 위상은 공란입니다.

## 열방정식과 푸리에 급수의 연결

길이 $\ell$인 막대에서 $u_t=\alpha u_{xx}$를 계산합니다. 경계조건은 $u(0,t)=T_0$, $u(\ell,t)=T_1$입니다. 정상 상태 $g(x)=T_0+(T_1-T_0)x/\ell$를 먼저 분리합니다.

$$u(x,t)\approx g(x)+\sum_{n=1}^{N}b_n\sin\frac{n\pi x}{\ell}\exp\left[-\alpha\left(\frac{n\pi}{\ell}\right)^2t\right]$$
$$b_n=\frac{2}{\ell}\int_0^{\ell}[u(x,0)-g(x)]\sin\frac{n\pi x}{\ell}\,dx$$

잔차 함수를 기확장하여 기존 푸리에 계수 함수를 재사용합니다. 입력에는 `x`와 `ell`을 사용할 수 있습니다. 시간별 온도 곡선, 시공간 히트맵, 사인 계수, 잔차 에너지, 시간 애니메이션을 제공합니다. 초기 함수와 경계 온도가 맞지 않으면 안내문을 표시하며, 해의 끝점은 경계조건으로 고정합니다. 열확산계수의 차원은 길이²/시간입니다.

이 방법은 일정한 열확산계수와 시간에 무관한 Dirichlet 경계조건을 가정합니다. 일반적인 PDE 수치 해석기나 유한차분법은 아닙니다.

### 열방정식 정확도 비교

**초기 재구성** 탭은 t=0에서 초기 함수와 유한 사인 급수의 차이를 표시합니다. 시간에 따른 온도 감소와 재구성 오차를 구분하십시오. 수치 표의 **정확도 비교**에는 기준 결과, 적분 표본 수를 `2*num_points-1`로 바꾼 결과, 차수를 `min(2*N,200,num_points-2)`로 바꾼 결과가 있습니다. 비교는 공통 2049개 평가점에서 수행합니다. 표본 수를 바꿀 때는 N을, N을 바꿀 때는 적분 표본 수를 유지합니다. 초기 재구성 RMSE, 기준과의 초기·최종 시각 최대 차이를 함께 제공합니다. 두 근사 해의 차이가 작아도 참해에 대한 오차가 작다고 보장하지는 않습니다.

## 파동방정식과 열방정식 비교

일정한 속력 c의 고정단 현에서 $u_{tt}=c^2u_{xx}$, $u(0,t)=u(\ell,t)=0$을 계산합니다. 초기 변위 $f(x)$와 초기 속도 $v(x)$의 사인 계수를 각각 $A_n,V_n$이라 하면 다음과 같습니다.

$$\omega_n=cn\pi/\ell,\qquad u(x,t)\approx\sum_{n=1}^{N}\left[A_n\cos(\omega_nt)+\frac{V_n}{\omega_n}\sin(\omega_nt)\right]\sin\frac{n\pi x}{\ell}$$

초기 속도 계수는 시간 미분 조건을 맞추기 위해 $\omega_n$으로 나눕니다. 초기 변위·속도에서 x와 ell을 사용할 수 있습니다. 시간별 변위, 시공간 히트맵, 계수·에너지 표 및 애니메이션을 제공합니다. 감쇠·외력·시간에 따라 바뀌는 경계조건은 구현하지 않았습니다.

단위 선밀도의 에너지는 $E=\frac12\int_0^\ell(u_t^2+c^2u_x^2)dx$이며 모드의 직교성을 이용해 계산합니다. 무감쇠 모형에서 일정해야 하지만 에너지 보존만으로 급수 절단 오차를 판단할 수는 없습니다.

**열·파동 비교** 탭에서는 동일한 초기 모양과 0 경계조건의 열방정식을 함께 계산합니다. 비교 α는 열 결과에만 사용됩니다. 열은 감쇠하고 파동은 진동하는 차이를 공통 세로축 범위로 관찰하십시오. 두 방정식의 u는 서로 다른 물리량이므로 모양의 수학적 비교입니다. 파동에만 초기 속도가 적용됩니다.

시간 표본은 출력 간격이며 수치 시간 적분의 간격이 아닙니다. 최고 차수 모드의 한 주기당 출력이 10개 미만이면 안내합니다. 작은 고차 계수까지 포함한 보수적 안내이므로 필요하면 시간 범위를 줄이거나 표본 수를 늘리십시오.

- 푸리에 `x`, L=`pi`: $a_0\approx0$, $a_n\approx0$, $b_n\approx2(-1)^{n+1}/n$입니다.
- `3`: 배열 전체가 상수로 평가되며 $a_0\approx3$입니다.
- `sign(x)`: N을 늘리면서 불연속점 주변 Gibbs 진동을 관찰하십시오.
- 열방정식 `sin(pi*x/ell)`: $u=e^{-\alpha(\pi/\ell)^2t}\sin(\pi x/\ell)$와 비교하십시오.
- 초기 온도 `20+60*x/ell`, 경계 20·80: 시간에 무관한 정상 상태입니다.
- 파동 초기 변위 `sin(pi*x/ell)`, 초기 속도 `0`: $u=\cos(c\pi t/\ell)\sin(\pi x/\ell)$와 비교하십시오.
