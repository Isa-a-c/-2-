# 공통 실험 화면 설계

BEFORE: 21개 주제를 단원별로 선택하고 모든 그래프를 즉시 그렸습니다.

AFTER: 실험군 → 문제 → 지원 구성으로 선택하고 교재 바로가기를 유지합니다. 기존 topic ID와 설정 JSON 버전 2, 풀이 공식 및 지원 범위를 보존합니다.

## 역할과 확장 규칙

- `topics/catalog.py`: 6개 실험군과 문제·영역·해법의 지원 조합입니다. 수학 라이브러리를 가져오지 않습니다.
- `topics`: 입력 명세·결과·계산 연결입니다. 상태를 가진 계산 객체는 호출자별로 분리합니다.
- `core`: GUI와 독립적인 수학 계산·저장입니다.
- `ui`: 공통 입력·수치 설정·그래프·재생·저장입니다.
- 교재 예제: 지원 구성과 매개변수·학습 설명의 묶음입니다.

함수 전개·근사 4개, 고유값·고유함수 1개, 적분변환·표본화 5개, 진동·ODE 2개, PDE·공간 분포 8개, 수식·해 검산 1개입니다. 반무한 PDE는 열·파동 두 구성에서 같은 계산 모듈을 사용합니다.

새 기능은 기존 결과 형태를 먼저 재사용하십시오. 행렬·경로·네트워크는 실제로 필요할 때 입력과 시각화 부품을 추가합니다. 실수·복소수, 좌표 축, 단위, 기저 항 번호는 명시적으로 구분합니다. 기호식과 수렴 조건을 일반 실수 곡선으로 강제 변환하지 않습니다. 지원하지 않는 문제·경계조건 조합은 등록하지 않습니다.

## 최적화와 검증

선택한 모듈만 가져오고 보이지 않는 그래프의 Qt 캔버스 생성·그리기를 지연합니다. 기존 figure 생성 API는 유지하므로 모든 그래프의 수학적 구성이 지연되는 것은 아닙니다. 큰 시공간 표는 원본 배열을 참조하는 행 뷰로 제공합니다. 동일한 성공 입력은 현재 결과를 재사용합니다.

`scripts/benchmark_workbench.py`로 같은 PC에서 모듈 로딩과 결과 표시 시간을 비교합니다. 표 배열 바이트는 원본 계산 배열을 제외한 추가 표 저장량이며 전체 메모리와 다릅니다. 성능 검사는 수학·설정 호환성·CSV·Qt 검사를 대신하지 않습니다.

소스는 Git으로 관리하며 노트북은 소스를 생성하지 않습니다. 이전 GUI 참조를 옮긴 후 코드를 제거합니다. 가상환경과 최신 배포본은 유지합니다. 오래된 배포본은 과거 버전이므로 현재 소스의 변경을 반영하지 않습니다.


## v1.7 변경

- `ui/jobs.py`: 작업 프로세스를 한 번 띄워 요청을 순서대로 처리합니다. 결과에는 작업 번호를 붙여 늦게 도착한 이전 결과를 버립니다. 계산 중 취소·새 요청은 프로세스를 종료하고 다음 요청에서 다시 시작합니다. 쉬는 동안 나머지 주제 모듈을 미리 가져옵니다. 화면의 "계산 중" 판단은 `job.busy`입니다.
- `core/quadrature.py`: 경계값의 도약점을 찾아 구간을 나눈 Gauss–Legendre 구적입니다. 퍼텐셜·직사각형 정상 상태·주기 2L 계수에 사용합니다.
- `topics/textbook.py`: 교재 본문 예제(절-번호, 쪽수, 주제, 입력)를 데이터로 관리하고 `get_topic`이 예제 목록 앞에 붙입니다. 기능이 없는 예제는 `UNSUPPORTED`에 이유와 함께 둡니다(현재 없음).
- 주제가 `migrate(params)`를 제공하면 설정 불러오기에서 이전 값의 이름을 바꿉니다(예: 11.10 공식 이름). 의미가 사라진 설정 항목은 `core/project.py`의 `RETIRED_KEYS`에서 제거합니다.
- 주제 24개, 지원 구성 27개입니다. 같은 주제의 다른 구성(열전도 고정/단열, 무한/반무한 막대)은 `mode`를 잠근 카탈로그 항목으로 연결합니다.
- 테스트는 주제 목록의 위치가 아니라 교재 절 번호(`lesson`)로 주제를 고릅니다.

## v1.9.2 시간 재생과 길이 변수

- '시간별 …' 탭은 `FigureAnimator(figure, series=topic.animation(result))`로 만듭니다. `_LiveCurve`가 재생 중 스냅숏 곡선을 숨기고 전체 시간 표본의 곡선 하나를 움직이며, 모든 프레임이 보이도록 세로 범위를 넓힙니다. 마지막 프레임에서는 원래 스냅숏 그래프로 돌아옵니다.
- 전체 데이터가 없는 t=… 곡선 묶음(열·파동 비교)은 `_Sequence.exclusive`로 현재 시각의 곡선만 보입니다. 차수별 곡선과 기저 함수는 계속 쌓아서 비교합니다.
- 길이 변수 이름을 `l`로 바꾸었습니다. `core.expr._parse`는 변수에 `l`이 있으면 `ell`을 같은 기호로 받아 예전 JSON 설정과 호환됩니다.

## v1.9.1 재생 막대 보완

- 세로축 이름이 t인 색 지도(시공간 히트맵)는 `_TimeLine`이 시간선을 움직입니다. 프레임은 QuadMesh의 칸 중심, 즉 실제 시간 표본이며 최대 120개로 줄입니다. x–y 평면의 색 지도는 시간축이 없어 정지 그래프입니다.
- 재생·일시정지·정지 단추를 따로 둡니다. 재생 중에는 재생 단추가 꺼지고 일시정지·정지가 켜집니다. 정지는 마지막 프레임(원래 그래프)으로 돌아갑니다. ◀◀/▶▶와 PageUp/PageDown은 전체 프레임의 약 10%씩, ←/→는 한 프레임씩 이동합니다.

## v1.9.0 그래프 재생과 확대

- `ui/player.py`의 `FigureAnimator`는 주제 코드를 고치지 않고 Figure에 그려진 선을 조사해 프레임을 만듭니다. 실선이 셋 이상인 축은 그린 순서대로 한 개씩 보이고(`_Sequence`), 실선 한두 개·표식 점·줄기·막대는 왼쪽부터 그려 나갑니다(`_Sweep`, 60프레임). 점선·파선은 기준선으로 남기고, 색 지도·등고선만 있는 축은 정지 그래프입니다. 마지막 프레임은 원래 그래프와 같습니다(테스트로 모든 그래프에서 확인).
- 주제의 `animation()` 데이터는 `evolution_figure`로 '변화 과정' 탭 그래프가 되며, 프레임은 탭을 처음 열 때 계산합니다. 예전 `AnimationDialog`(별도 창)는 삭제했습니다.
- `PlayerBar`는 처음·이전·재생·다음·끝 단추, 슬라이더, 속도(0.25×~4×), 한 번·반복·왕복을 제공합니다. 1× 속도에서 프레임 수와 관계없이 약 4초 동안 재생합니다. 탭을 바꾸면 보이지 않는 탭의 재생은 멈춥니다.
- `ZoomCanvas`는 Ctrl+휠로 마우스 아래 점을 고정한 채 확대·축소하고(로그 축 포함), Shift+휠로 좌우 이동합니다. 바꾸기 전 범위를 도구 모음 기록에 넣으므로 더블클릭이나 홈 단추로 돌아갑니다.
- 상권 복습 화면(`topics/ode.py`, `topics/laplace.py`, `core/custom_ode.py`)과 관련 테스트·노트북 셀을 삭제했습니다. 주제는 22개, 구성은 25개입니다.

## v1.8.0 화면 편의

- `ui/experiments.py`의 `ExperimentSelector`는 콤보 상자 네 개 대신 장 → 절 → 예제 트리와 검색창입니다. 기존 API(`select`, `setCurrentIndex`, `findData`, `experiment`, `currentIndexChanged`)는 그대로이고, 예제를 누르면 `exampleChosen(name)`을 보냅니다. 예제 항목은 주제 모듈을 가져와야 하므로 절을 처음 펼치거나 선택할 때 채웁니다(시작 시간 유지).
- `MainWindow`는 입력이 바뀌면 450 ms 뒤 자동 계산합니다. 같은 구성의 마지막 계산(그래프 포함)이 1초를 넘으면 쉬고, 작업 프로세스를 새로 띄운 첫 계산(`CalculationJob.cold`)은 가져오기 시간이 섞이므로 시간 기록에서 뺍니다. 계산 중에는 작업 프로세스를 끊지 않고 끝난 뒤에 이어서 계산합니다. 자동 계산의 오류는 대화상자 없이 안내 줄에 표시합니다.
- 같은 구성을 다시 계산하면 보던 탭과 표 탭을 유지합니다. 표는 6자리로 보이고 풍선 도움말·Ctrl+C 복사는 전체 정밀도입니다. 글자 배율은 `QSettings`에 저장하며 Matplotlib `font.size`도 함께 바꿉니다. 테스트는 `MainWindow(settings)`에 임시 INI 파일을 넘겨 사용자 설정을 건드리지 않습니다.
