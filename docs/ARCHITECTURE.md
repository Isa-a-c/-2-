# 공통 실험 화면 설계

BEFORE: 21개 주제를 단원별로 선택하고 모든 그래프를 즉시 그렸습니다.

AFTER: 실험군 → 문제 → 지원 구성으로 선택하고 교재 바로가기를 유지합니다. 기존 topic ID와 설정 JSON 버전 2, 풀이 공식 및 지원 범위를 보존합니다.

## 역할과 확장 규칙

- `topics/catalog.py`: 6개 실험군과 문제·영역·해법의 지원 조합입니다. 수학 라이브러리를 가져오지 않습니다.
- `topics`: 입력 명세·결과·계산 연결입니다. 상태를 가진 계산 객체는 호출자별로 분리합니다.
- `core`: GUI와 독립적인 수학 계산·저장입니다.
- `ui`: 공통 입력·수치 설정·그래프·재생·저장입니다.
- 교재 예제: 지원 구성과 매개변수·학습 설명의 묶음입니다.

함수 전개·근사 4개, 고유값·고유함수 1개, 적분변환·표본화 5개, 진동·ODE 2개, PDE·공간 분포 8개, 수식·해 검산 1개입니다. 반무한 PDE는 열·파동 두 구성에서 같은 계산 모듈을 사용합니다.

새 기능은 기존 결과 형태를 먼저 재사용하십시오. 행렬·경로·네트워크는 실제로 필요할 때 입력과 시각화 부품을 추가합니다. 실수·복소수, 좌표 축, 단위, 기저 항 번호는 명시적으로 구분합니다. 기호식과 수렴 조건을 일반 실수 곡선으로 강제 변환하지 않습니다. 지원하지 않는 문제·경계조건 조합은 등록하지 않습니다.

## 최적화와 검증

선택한 모듈만 가져오고 보이지 않는 그래프의 Qt 캔버스 생성·그리기를 지연합니다. 기존 figure 생성 API는 유지하므로 모든 그래프의 수학적 구성이 지연되는 것은 아닙니다. 큰 시공간 표는 원본 배열을 참조하는 행 뷰로 제공합니다. 동일한 성공 입력은 현재 결과를 재사용합니다.

`scripts/benchmark_workbench.py`로 같은 PC에서 모듈 로딩과 결과 표시 시간을 비교합니다. 표 배열 바이트는 원본 계산 배열을 제외한 추가 표 저장량이며 전체 메모리와 다릅니다. 성능 검사는 수학·설정 호환성·CSV·Qt 검사를 대신하지 않습니다.

소스는 Git으로 관리하며 노트북은 소스를 생성하지 않습니다. 이전 GUI 참조를 옮긴 후 코드를 제거합니다. 가상환경과 최신 배포본은 유지합니다. 오래된 배포본은 과거 버전이므로 현재 소스의 변경을 반영하지 않습니다.


## v1.7 변경

- `ui/jobs.py`: 작업 프로세스를 한 번 띄워 요청을 순서대로 처리합니다. 결과에는 작업 번호를 붙여 늦게 도착한 이전 결과를 버립니다. 계산 중 취소·새 요청은 프로세스를 종료하고 다음 요청에서 다시 시작합니다. 쉬는 동안 나머지 주제 모듈을 미리 가져옵니다. 화면의 "계산 중" 판단은 `job.busy`입니다.
- `core/quadrature.py`: 경계값의 도약점을 찾아 구간을 나눈 Gauss–Legendre 구적입니다. 퍼텐셜·직사각형 정상 상태·주기 2L 계수에 사용합니다.
- `topics/textbook.py`: 교재 본문 예제(절-번호, 쪽수, 주제, 입력)를 데이터로 관리하고 `get_topic`이 예제 목록 앞에 붙입니다. 기능이 없는 예제는 `UNSUPPORTED`에 이유와 함께 둡니다(현재 없음).
- 주제가 `migrate(params)`를 제공하면 설정 불러오기에서 이전 값의 이름을 바꿉니다(예: 11.10 공식 이름). 의미가 사라진 설정 항목은 `core/project.py`의 `RETIRED_KEYS`에서 제거합니다.
- 주제 24개, 지원 구성 27개입니다. 같은 주제의 다른 구성(열전도 고정/단열, 무한/반무한 막대)은 `mode`를 잠근 카탈로그 항목으로 연결합니다.
- 테스트는 주제 목록의 위치가 아니라 교재 절 번호(`lesson`)로 주제를 고릅니다.
